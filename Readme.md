# Event Planner App

## Overview
Event Planner App is an Android application developed using Kotlin and Jetpack Compose in Android Studio. The app allows users to add, edit, view, and delete events.

## Features
- Add new events
- Edit existing events
- Delete events
- View event list
- Date and time picker
- Event category selection
- Input validation
- Persistent data storage using Room Database

## Technologies Used
- Kotlin
- Jetpack Compose
- Room Database
- Android Studio

## Screens Included
- Event List Screen
- Add Event Screen
- Edit Event Screen
